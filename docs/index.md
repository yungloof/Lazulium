# Lazulium

Todos os jogos do PC num lugar só: Steam, Epic, GOG, Battle.net, EA App, Ubisoft Connect, Riot, Xbox, emuladores e jogos avulsos, com horas jogadas, conquistas, capturas e backup dos saves.

É um app grátis e de código aberto para Windows 10 e 11. Ele acha os jogos instalados, baixa as capas, conta as horas de qualquer jogo e guarda o histórico até dos que você desinstalou. Dá para usar com mouse, teclado ou controle.
